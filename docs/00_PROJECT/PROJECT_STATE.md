## 3. 最近用户反馈（待办而非架构变更）

### RTI-001 — 悬浮层遮挡刷题页面
症状：实时互动测试中心所示采集画面中，悬浮球及迷你对话窗口遮挡题目/材料。

需要确认：
- 实际截图发生在什么时点；
- 使用的是隐藏窗口还是仅将覆盖矩形涂黑；
- 输入法是否仍在画面中；
- 是否拒绝旧帧并确认采集的是隐藏后的新帧；
- 采集成功、失败、超时后，窗口和输入法是否恢复到原状态。

验收：在真实第三方刷题页面发送问题时，最终证据帧不包含 Hanako 浮层遮挡/键盘噪声；所有异常路径均能恢复窗口，不会重复添加窗口或丢失证据。

### RTI-002 — 题干与选项可见，但材料数据未进入模型
症状：模型复述“2017年1—10月，住宅投资占房地产开发投资的比重约为”及选项，但无法获得计算所需的住宅投资额和房地产开发投资额。

需要逐段核对：屏幕帧 → OCR/无障碍结果 → EvidenceRecord → ClassifiedBlock → AssembledQuestionContext → 最终请求的文本和图像 payload。确认是否存在截断、过度过滤、同题关联失败、图像未发送或端点不支持视觉等情况。

验收：在可复现的题目中，测试中心能指出关键数字来自哪个 evidenceId/视口，并能证明这些信息实际进入模型请求；不能证明时，系统清楚显示缺失项而不猜答案。

### RTI-003 — 测试中心导出、复制和长按选取
用户要求：
- 顶部增加“导出全部测试数据”和“分享为 TXT”等操作；
- 每个功能模块有独立的“复制全部内容”按钮；
- 模块中的长文本支持长按、选取部分文本和复制，尽量复用聊天页面的现有选择交互；
- 导出数据应包含实际采集、过滤、上下文、图像元信息、请求追踪、错误与时间，敏感密钥必须脱敏。

当前源码快速检查：RealtimeTestCenterScreen.kt 中未发现明确的 share/copy/SelectionContainer/selectable 实现。施工前仍需与聊天页现有文本选择方案比较。

验收：导出的 TXT 可单独用于定位一次失败；复制按钮复制完整模块数据；长按选择不破坏页面滚动和按钮点击。
